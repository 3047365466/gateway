Rapid Console Frontend Setup

To properly set up the Rapid Console frontend, you need to download and place several JavaScript and CSS libraries in the correct directories.

Required Libraries

Library Version Download URL Target Location
Vue.js 2.6.14 Download js/vue.min.js
Vue Router 3.5.3 Download js/vue-router.min.js
Axios 0.24.0 Download js/axios.min.js
Element UI (JS) 2.15.7 Download js/element-ui.js
Element UI (CSS) 2.15.7 Download css/element-ui.css

Directory Structure

Make sure your directory structure looks like this:

view/
├── assets/
│   └── logo.svg
├── css/
│   ├── element-ui.css
│   └── main.css
├── js/
│   ├── api.js
│   ├── axios.min.js
│   ├── components/
│   │   ├── RuleManagement.js
│   │   └── ServiceManagement.js
│   ├── element-ui.js
│   ├── main.js
│   ├── vue.min.js
│   └── vue-router.min.js
├── index.html
├── README.md
└── setup.html

Setup Instructions

  1. Download all required libraries from the links above
  2. Create the directory structure shown above
  3. Place each downloaded file in its target location
  4. Access the application at http://localhost:9005/ (or your configured port)
